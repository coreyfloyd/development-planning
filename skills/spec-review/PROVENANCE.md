# Provenance

Prior art: [mattpocock/skills](https://github.com/mattpocock/skills), MIT license,
upstream `to-spec`: product-level acceptance criteria, architecture seams and
specification self-checks. This self-authored independent checklist adapts those
ideas and the former local spec checklist; it is not a maintained upstream fork.

The existing-systems review check adapts the alternatives-evaluation idea from
[google/elephant-goldfish-model](https://github.com/google/elephant-goldfish-model)
at commit `8c29f560e300471d458b71d1131834e097b18d4f`, specifically
`resources/document_standards/feature-spec-standard.md` and
`skills/egm-draft/SKILL.md`. Upstream is Apache-2.0. This is a self-authored
adaptation; no upstream prose is copied.
